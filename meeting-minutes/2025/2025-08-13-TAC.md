* Next phase: x86 code integration (expected to take considerable time)

* Upcoming release planned for next few weeks

**mlkem-libjade**:
* Development in separate repository with releases integrated into PQCP
* Working on new release featuring:
  * Improved mlkem768
  * Newly added mlkem1024

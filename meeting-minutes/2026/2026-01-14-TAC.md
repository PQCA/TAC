### Project Updates

**OQS (Norman):** 
  - Norman mentioned the need to discuss project health metrics in the next OQS meeting. Norman mentioed TSC Chair and Vice Chair nominations are currently in progress.

**PQCP (Matthias):**
  - **mlkem-native**: All x86 assembly is now verified using HOL-Light, including the NTTs and rejection sampling; this was done by Hanno's colleagues at AWS [**@jargh**](https://github.com/jargh) [**@dkostic**](https://github.com/dkostic).
  - **mldsa-native**: Some work has been merged on reducing the memory consumption, but more work left to make it more suitable for memory-constrained devices.
  - **mldsa-native**: Completed integration into OpenTitan: [**[crypto] ML-DSA (FIPS 204) signature implementation** zerorisc/expo#184](https://github.com/zerorisc/expo/pull/184).
  - **mldsa-native & mlkem-native**: [**@davidchisnall**](https://github.com/davidchisnall) started using mldsa-native and mlkem-native for demoing PQC on CHERIoT: https://github.com/CHERIoT-Platform/cheriot-pqc/.
  - **mldsa-native**: TF-PSA-Crypto (formerly Mbed-TLS) started integration of mldsa-native: [**Integrate mldsa-native** Mbed-TLS/TF-PSA-Crypto#628](https://github.com/Mbed-TLS/TF-PSA-Crypto/issues/628).
  - Liam Fisher [**@f15hr**](https://github.com/f15hr) started his mentorship last week.

**CBOMkit (Andreas):**
  - TSC started to work: https://github.com/cbomkit/tsc/; New member voted in to TSC (Aditya). 
  - New repo (CBOM generation pipeline): https://github.com/cbomkit/cbomkit-pipeline for in-depth code analysis and dependency scanning.
